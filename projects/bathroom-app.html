Overview

The UVA Restroom Tracker is a map-based, social Android application built with Kotlin and Jetpack Compose. Inspired by review-tracking platforms like Beli, the app empowers users to discover, pin, and rate campus restrooms based on cleanliness, accessibility, and the availability of crucial amenities like feminine hygiene products. Backed by Firebase, the platform features secure user authentication, real-time syncing for crowdsourced reviews, and cloud storage for image uploads, providing a comprehensive and reliable facility guide for the university community.

My Role & Contributions

User Identity & Authentication

  • Secure Onboarding: Engineered the end-to-end user authentication flow using Firebase Auth, building custom account creation and login screens that seamlessly route successful logins to the main app dashboard.
  • Profile Management: Designed and implemented a dynamic EditProfileScreen, allowing users to customize their display names, pronouns, bios, and "favorite bathroom" statuses.

Media & Cloud Storage Integration

  • Dynamic Image Uploads: Integrated Firebase Storage and device camera functionality, enabling users to take a live photo or upload an image from their gallery to update their profile pictures.
  • Review Media: Connected the Firebase Storage bucket to the main posting workflow so users can attach and display photos alongside their restroom reviews, pulling the images dynamically from the cloud.

Backend Setup & Architecture

  • Database Configuration: Led the initial setup and integration of Cloud Firestore, establishing the data structure needed to handle real-time, user-generated reviews and location pins.
